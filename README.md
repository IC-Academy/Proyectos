# Portal de Objetivos en Cascada

Versión estática preparada para el repositorio `ic-academy/Proyectos`.

## Publicación

1. Elimina los archivos anteriores del repositorio.
2. Sube todo el contenido de este paquete a la raíz de `main`.
3. Incluye las carpetas `.github` y `assets`, además del archivo `.nojekyll`.
4. En Settings > Pages selecciona GitHub Actions.
5. Espera a que finalice `Publicar Portal de Objetivos`.

El archivo `index.html` ya está compilado. No se requiere Node.js, npm ni una
compilación adicional en GitHub.
